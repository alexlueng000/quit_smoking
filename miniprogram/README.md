# 戒烟伙伴 · 微信原生小程序

当前阶段：**本地体验版**。原生 TypeScript / WXML / WXSS，沿用已创建的 AppID。

## 打开项目

在微信开发者工具中导入本目录 `E:\claude_projects\quit_smoking\miniprogram`，然后点击“编译”。`project.config.json` 已配置源码根目录为里面的 `miniprogram/`，入口为 `pages/index/index`。

本地功能不需要数据库、微信登录、API 密钥或网络域名配置，也不需要构建 npm 运行时包。不要关闭开发者工具的域名校验。

## 已实现

- 首次进入首页可建立三步戒烟档案，填写草稿自动保存。
- 首页真实本地统计：今日烟瘾、累计未吸烟次数、7 天强度趋势、戒烟天数与预计节省。
- 烟瘾评分、8 个触发场景和可选补充说明。
- 按触发场景选择两步预设支持，合计约 2.5–3.5 分钟，可提前结束。
- 保存当前步骤和截止时间，切后台 / 重进页面按实际时间恢复。
- 干预后评分、三种结果、可选反馈；重复保存不重复累计。
- 每日记录可更新，日期按 Asia/Shanghai 计算，跨天后要求重新读取。
- 计划修改、隐私说明、确认后删除本设备数据。
- 存储失败显示错误，不把失败操作显示为已保存。

结果页默认评分与干预前一致，不预设改善。没有记录的趋势显示空态，真实 0 分与无记录区分显示。预计节省仅在已开始戒烟且填写烟价后展示，属于估算。

## 版本边界

**尚未接入服务端，也不调用生成式 AI。** 页面均明确标记本地体验；支持内容基于仓库已有 fallback 文案，不伪装成实时 AI 输出。

数据写入微信本地存储键 `quit-coach:local:v1`。清除小程序数据或更换设备会丢失本地记录，没有云端备份。数据删除只清除此键，不清空其他本地存储，也不影响网页账户。

当前支持内容会检查已有安全提示关键词，命中时停止普通练习并展示仓库既有求助提示；此能力不是诊断工具。

微信登录、服务端令牌、真实 AI、云端统计和多端同步属于迁移计划 M2 及后续阶段。接入时以 `services/coach.ts` 为服务边界，保留本地与服务端数据隔离，不自动上传现有本地记录。

## 验证

在仓库根目录（已有根项目依赖）运行：

```powershell
npm --prefix miniprogram run typecheck
npm --prefix miniprogram test
```

单独使用此项目时先在本目录运行 `npm install`，再运行 `npm run typecheck` 和 `npm test`。测试使用 Node 内置测试器与 TypeScript 转译器，不依赖 Prisma。

项目保持严格的业务代码类型检查；`skipLibCheck` 仅跳过模板附带的旧微信声明文件内部泛型兼容错误。

自动检查包含：档案校验、草稿、重复事件 / 步骤 / 结果、计时恢复、各场景预设、安全提示、统计、每日记录更新、跨天、存储失败、删除范围，以及原生页面路由和事件绑定。

本轮已使用开发者工具附带的 `wcc.exe` / `wcsc.exe` 编译模板与样式。电脑操作权限未授予微信开发者工具，尚未执行模拟器交互、iOS / Android 实机验收。

## 手动验收路径

1. 编译后首页应展示“建立我的戒烟档案”和本地体验说明，不应显示演示数据。
2. 填写档案，第二步选场景和原因；返回再进入应恢复内容。
3. 保存后进入“开始缓解烟瘾”，选分数与场景，开始支持。
4. 切后台后返回，倒计时按实际经过时间恢复；回首页再继续应进入同一步。
5. 点击下一步或提前结束，记录实际评分和结果。回首页确认统计更新。
6. 保存今天的吸烟数量，再次修改应更新同一条记录。
7. 使用测试数据验证删除确认；取消不删除，确认仅删除本设备当前版本记录。

完整路线图见 [迁移计划](../docs/miniprogram-migration-plan.md)。
